# Avlin Luiz — Portfolio Website

A responsive, one-page portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` — the complete website.
- `profile.jpg` — add your own profile photo here (optional).

## Add your photo
1. Choose a photo you are comfortable sharing publicly.
2. Rename the image file to `profile.jpg`.
3. Put it in the same folder as `index.html`.
4. Refresh the website.

If you do not add a photo, the website displays an initials placeholder.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new repository named `avlinluiz.github.io` (replace `avlinluiz` with your exact GitHub username).
2. Choose **Public**. Do not add a README, license or .gitignore if you are uploading this prepared folder.
3. Open the new repository and choose **Add file → Upload files**.
4. Upload `index.html` and, if you have added it, `profile.jpg`. You can also upload this README.
5. Enter a commit message such as `Add portfolio website`, then click **Commit changes**.
6. Open **Settings → Pages** in the repository.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait a few minutes and refresh the Pages settings. Your site should be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/`

If you use a repository name other than `YOUR-GITHUB-USERNAME.github.io`, the URL will usually be:
`https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`

## Before publishing
Review the contact email and decide whether you are comfortable displaying it publicly. GitHub Pages websites are public.
